# 响应式内容区宽度调整设计

## 目标

减少页面两侧无效留白，提升 1280px、1366px 等常见小显示器上的中间可用区域，同时保持宽屏下的阅读舒适度。

## 选定方案

采用“紧凑响应式”方案：

- 页面主容器宽度为 `calc(100% - 32px)`，即默认左右各保留 16px。
- 页面主容器最大宽度限制为 `1360px`，避免超宽显示器上的行长过长。
- 主容器使用 `width: 100%` 配合 `max-width`，而不是固定宽度。
- 在窄屏（小于 720px）下进一步使用左右 12px 内边距，保留现有内容的可读性。
- 表格继续在自身区域内处理溢出，不改变字段、按钮和业务交互。

## 影响范围

- 仅调整 `src/main/resources/static/index.html` 中全局 `.container` 的布局规则，并视实际效果补充 `app.css` 中的响应式覆盖。
- 不改动导航结构、卡片样式、表格列定义和 JavaScript 逻辑。

## 验证标准

- 1280px 宽度下，左右空白明显小于当前页面，中间内容区可完整容纳侧栏、主卡片和常用操作按钮。
- 1366px 及以上宽度下，内容区不超过 1360px 且保持居中。
- 375px 移动宽度下无页面级横向溢出；需要滚动的表格仅在表格区域内滚动。
